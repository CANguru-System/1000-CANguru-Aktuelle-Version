# Testvektoren für das CANguru-Protokoll Version 2
#
# Beide Implementierungen (C++ für Decoder/Bridge, C# für die GUI) müssen diese
# Nachrichten gleich zerlegen und - bei OK - wieder bitgenau erzeugen.
#
# Format:  Name | Bytes (hex) | Erwartung
# Erwartung:
#   OK F=<Feature> K=<Kommando> FL=<Flags> S=<Folgenummer> D=<Decoder> P=<Nutzdaten hex oder ->
#   FEHLER <TooShort|WrongMagic|Truncated>
# Bei OK wird außerdem neu kodiert und mit den ersten 8 + Länge Bytes verglichen.
